# SABC 项目优先级评估

面向小团队管理者的浏览器本地项目决策工具。模型负责识别项目类型、提取事实、证据和风险；固定 TypeScript 规则负责七维加权、证据上限、置信度、S/A/B/C 门槛与一票否决。模型不能直接决定最终等级。

## 本地启动

需要 Node.js 20.9 或更高版本。PowerShell 中执行：

```powershell
Copy-Item .env.example .env.local
npm.cmd install
npm.cmd run dev
```

然后打开 [http://localhost:3000](http://localhost:3000)。如果端口已占用，Next.js 会在终端显示实际地址。

在 `.env.local` 中配置：

```dotenv
DEEPSEEK_API_ENDPOINT=https://yunwu.ai/v1/chat/completions
DEEPSEEK_MODEL=gpt-5.6-luna
DEEPSEEK_API_KEY=填入新密钥
```

聊天记录里曾经出现过的旧密钥必须立即在模型服务控制台撤销并重新生成。替换密钥只能写入未跟踪的 `.env.local`，不要放进源码、浏览器代码、测试、截图、日志或提交记录。

## 四阶段流式工作流

第一智能体访谈 → AnySearch 联网调研 → 第二智能体评估讨论 → 用户点击后生成最终报告

第一智能体只通过流式对话收集项目事实，不在每轮对话中生成或更新评级。问答深度支持低、中、高三档，默认中档；AI 在信息充分时可以建议结束，但只有用户点击“结束信息收集并开始调研”才会进入下一阶段。

调研阶段独立运行公开关键词提炼、AnySearch 联网调研、综合分析和一次固定规则评分，并在页面中显示真实检索词与来源数量。完成后自动进入第二智能体：它会先说明“根据调研，目前建议将这个项目评为 X 级”、解释原因并继续追问。用户补充的新事实足以改变判断时，第二智能体可以调整建议等级；信息充分时它可以建议生成报告，但不能代替用户触发。

只有用户点击“生成最终报告”后，系统才会复用已保存的调研结果，综合第一阶段访谈和第二阶段讨论，计算最终评级并保存报告。报告页可返回第二智能体继续讨论；再次生成时会用新报告原子覆盖旧报告，不会重新调用 AnySearch。

使用 `npm.cmd run smoke:stream` 可验证供应商是否真实返回多个内容片段。脚本只输出状态、片段数量和首片段耗时，不输出模型内容或密钥。运行配置只保存在未跟踪的 `.env.local` 中；任何曾粘贴到聊天或日志中的密钥都应立即轮换。

## 使用边界

- 项目、消息、评级快照和报告只保存在当前浏览器的 IndexedDB 中，不会自动同步到其他设备。
- 清除该站点的浏览器数据会永久丢失项目历史；需要留档时先生成报告并导出 PDF。
- 报告的“导出 PDF”会打开浏览器原生打印对话框，选择“另存为 PDF”即可。
- 当前 Chat Completions 接口本身不被当作联网查证工具。没有可复查来源时，外部事实仍标记为未验证。
- 临时评级表示仍有关键证据缺口；最终评级只说明已满足当前规则的定级条件，不代表自动投资建议。

## 质量检查

```powershell
npm.cmd test
node --test scripts/check-client-secrets.test.mjs
npm.cmd run lint
npm.cmd run build
npm.cmd run security:client
npm.cmd run e2e
```

`security:client` 必须在成功构建后运行，只检查客户端静态产物和客户端引用清单；发现疑似密钥时只报告规则和文件，不输出密钥内容。

如需用一枚已经轮换的新密钥做最小服务端连通性检查，请先在当前 PowerShell 会话或 `.env.local` 中配置它，再执行：

```powershell
npm.cmd run smoke:ai
```

通过模拟测试和构建不等于真实模型请求已经通过。交付验收时仍应完成一次真实项目评估、一次追问和一次中文 A4 PDF 保存。

## 主要流程

1. 输入自由格式项目描述，创建浏览器本地案卷。
2. 第一智能体逐轮追问，每次只处理一个最有价值的信息缺口，访谈阶段不评分。
3. 用户结束信息收集后进入独立等待页，系统联网调研并把搜索结果交回模型综合分析。
4. 本地规则在调研完成后形成进入讨论阶段的建议等级，不生成报告。
5. 第二智能体以普通聊天解释建议等级、继续追问，并可依据新事实调整建议。
6. 用户手动点击后才生成最终报告；可返回继续讨论、重新生成覆盖，或导出 PDF。
7. 只有已经生成最终报告的项目才进入横向对比。

网络、模型拒绝、超时、结构校验、本地存储和报告保存会显示不同的中文错误。网络重试只重放最后一次分析请求，不重复用户消息；本地保存失败只重试 IndexedDB 写入，不会再次调用模型。
